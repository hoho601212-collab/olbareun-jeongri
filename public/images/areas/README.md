# 부산 지역별 유품정리 이미지 업로드

이 폴더는 `/busan/[slug]` 페이지의 지역 이미지용입니다.

업로드 형식: WebP, 권장 비율 3:2 (예: 1536×1024).

파일명 (코드에서 현재 참조하는 이름):

nam.webp
buk.webp
haeundae.webp
saha.webp
geumjeong.webp
gangseo.webp
yeonje.webp
suyeong.webp
sasang.webp
gijang.webp

참고: 이전에 제작한 `*-hero.webp` 파일을 업로드할 때에는 `-hero`를 제거하여 이름을 맞추세요. 예: `sasang-hero.webp` → `sasang.webp`.

현재 지역별 페이지의 `LOCAL SCENE` 이미지에 연결됩니다. 페이지 최상단 히어로 배경에 적용하려면 별도의 코드 수정이 필요합니다.
